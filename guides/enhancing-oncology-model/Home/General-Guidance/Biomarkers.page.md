<p>
The <b>EOM Tumor Marker Test Profile</b> must be submitted for each <b>Estrogen Receptor (ER), Progesterone Receptor (PR), and HER2 Tests</b> for all beneficiaries with an attributed cancer type of <b>Breast Cancer</b>. As indicated in the <a href="https://build.fhir.org/ig/FirelyTeam/enhancing-oncology-model-ig/StructureDefinition-eom-tumor-marker-test.html">EOM Tumor Marker Test Profile</a> an Observation.code must be reported leveraging the <a href="https://hl7.org/fhir/us/mcode/ValueSet-mcode-tumor-marker-test-vs.html">Tumor Marker Test Value Set</a>. For EOM there are specific LOINC codes permitted for each ER, PR, and HER2 from this value set. The codes accepted for EOM are noted below.</p>
